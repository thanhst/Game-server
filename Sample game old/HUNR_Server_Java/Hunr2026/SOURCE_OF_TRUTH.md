# Source of Truth - Java Server

Thư mục này là nơi chứa source code Java gốc (source of truth) dùng để đối chiếu với server C++.

## Mục đích
- Tất cả logic game và protocol từ Java server được coi là nguồn tham chiếu chính
- Khi có sự khác biệt giữa C++ và Java, cần đối chiếu với code trong thư mục này

## Cấu trúc
- `src/` - Source code Java
- `docs/` - Tài liệu kiến trúc
